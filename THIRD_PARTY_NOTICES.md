# Dependencies and data

This project uses Ultralytics YOLO (the installed distribution identifies its license as AGPL-3.0), PyTorch, torchvision, OpenCV, FastAPI, Pillow and other Python packages. Their own licenses and notices remain applicable. The Ultralytics distribution's license text is included in `LICENSE-ULTRALYTICS`.

The bundled detector was trained from scratch with Ultralytics, not copied from a pretrained image dataset. Images and labels were generated by `scripts/generate_data.py`; they are synthetic and contain no real factory photographs. Sample images use a separate random seed. Model artifacts and dependency code are not represented as exclusively original source authored by the student.
